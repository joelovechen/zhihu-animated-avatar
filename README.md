# 知乎动态头像助手 2.2（非官方）

支持 Chrome / Edge（Chromium 111+，建议最新版）。无需构建，无外部运行依赖。

本项目免费开源，采用 MIT 许可证。完整代码可审查，不包含广告、分析 SDK 或远程可执行代码。

## 安装或更新

1. 打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式。
2. 选择「加载已解压的扩展程序」，选中本目录（包含 `manifest.json` 的目录）。已有旧版则点击扩展的「重新加载」。
3. **刷新已打开的知乎页面**，再进入自己已登录的「我的主页」。升级时必须刷新，以移除旧版留在页面中的全局注入。
4. 点击扩展图标。选择 GIF 或动态 WebP，等待显示「动图已准备好」。大文件建议先点「在独立页打开」，转换时保持页面打开。

## 第一种：手动替换（作者的方式）

1. 准备好动图后，点击「启用手动替换」。
2. 页面状态显示已就绪后，回到**同一个知乎标签页**，按平时的方式更换头像。
3. 任选一张知乎支持的图片作为占位图，点击保存。裁剪窗口显示的占位图、裁剪结果不会改变实际上传的动图；插件把 Canvas 导出的数据替换为准备好的完整 WebP。
4. 重新打开扩展查看拦截次数。次数大于零仅说明发生了数据替换，**不代表知乎服务端接受了头像**。
5. 完成后点击「停止当前页替换」。也可刷新页面停止。10 分钟后自动恢复。

启用期间，当前页所有 `HTMLCanvasElement.toBlob/toDataURL` 导出均会被替换，与文章方法一致；此时只操作头像，完成后停止。其他标签页不会自动启用，图片缓存也不会在刷新后自动注入。

## 第二种：自动更换

在自己的知乎主页准备好动图，点击「自动更换头像并保存」。插件尝试：

1. 定位唯一的头像文件输入框，必要时点击「修改头像」等入口。
2. 填入本地生成的 PNG 占位图。
3. 等待头像裁剪窗口及可用的保存按钮，自动点击保存。
4. 检查保存期间是否拦截到 Canvas 导出，并等待裁剪窗口关闭，然后停止替换。

无需再次手动点击知乎的更换头像按钮。只调用页面现有 UI 流程，不猜测私有上传接口。当前自动适配识别 `.ProfileHeader-avatar` / `.UserAvatarEditor`、明确的头像入口、带头像标题或头像编辑器的弹窗。

遇到入口不唯一、找不到编辑器、保存超时等情况，会保留手动替换状态并提示手动操作；不会自动重复提交。可点击「停止当前页替换」中止后续自动步骤，但已经发出的上传无法撤回。整个自动过程在目标页执行，插件小弹窗关闭不会取消它，再打开可查看进度。

自动模式已经过实际使用验证。知乎页面改版后，入口或按钮结构仍可能变化；遇到定位失败时会保留手动替换模式。「完成页面保存流程」表示扩展已执行并观察到当前页面的保存流程，不代表知乎服务端一定接受，请以知乎反馈与实际显示为准。

## 图片处理与限制

- GIF：浏览器 `ImageDecoder` 逐帧解码和合成，Canvas 将每帧编码为 WebP，再按 RIFF 规范封装为动画。保留有效帧时长及透明度；GIF 输出默认无限循环，编码质量 0.9（有损）。
- WebP：逐帧解码校验，保持原始文件字节不变。只接受至少两帧的动画。
- 文件按内容识别，不依赖后缀或浏览器提供的 MIME 类型。
- 本地保护限制：输入和输出最大 20MB，最大 600 帧，单帧最多 4096×4096 像素，总帧像素最多 3 亿。超限请先缩小或缩短动画。
- 2.5MB 为建议大小，**不是已知的知乎官方上传上限**。本地验证通过也不能保证服务端接受。
- 插件不向外部转换服务发送图片、不收集 Cookie。仅在用户触发换头像时交给知乎现有上传流程。准备好的图片保存在扩展本地存储中，可点击「删除本地图片」。
- 知乎部分页面、客户端版本可能只显示首帧。服务端也可能转码或拒绝该文件。

## 文件与权限

- `media.js`：GIF 解码、WebP 封装与验证。
- `injector.js`：页面主世界 Canvas 替换、自动流程与状态。
- `popup.html / popup.css / popup.js`：选择图片、预览、模式按钮与页面回执。
- `author.html / author.css / author.js`：本地作者页，依次读取 Cloudflare、GitHub、浏览器缓存和内置内容；只解析经过限制的 JSON 文本与 HTTPS 链接。
- `storage` / `unlimitedStorage`：保存本地动图（应用仍有 20MB 文件限制）；`activeTab` / `scripting`：仅在用户点击扩展后，对当时选中的知乎标签页执行指令。
- `host_permissions`：仅用于作者页读取 Cloudflare 主源和 GitHub Raw 备用源。扩展没有常驻内容脚本、远程脚本、后台数据采集或外部消息桥。未由用户启用替换时不修改页面 Canvas。

## 更新作者页内容

编辑 `author-content/author-content.json` 后提交到 GitHub，再把同一数据写入 `cloudflare/worker.js` 并部署。不要在内容中加入 HTML 或 JavaScript；客户端只接受结构版本 1、短文本和 HTTPS 链接。

## 验证

单元测试：在本目录执行 `npm test`，无需 `npm install`。

发布构建：执行 `python tools/build_release.py`。扩展 ZIP、商店资料包和 SHA-256 校验文件会写入 `local-artifacts/releases/current/v当前版本/`；该本地归档目录不会提交到 Git。

浏览器集成测试：在本目录执行 `python -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/tests/browser.html`，点击「运行全部测试」。验证真实 ImageDecoder/Canvas 的透明动画转换、帧时长、逐字节替换、自动填图保存、动态文件输入框、取消和超时回退。测试使用本地合成素材，不访问知乎。

`tests/preview.html` 用开发用的模拟 Chrome 接口测试实际弹窗交互；它不是扩展环境，不能代替真实浏览器扩展与知乎联调。发布 ZIP 不包含测试文件。
