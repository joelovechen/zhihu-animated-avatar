# Microsoft Edge 加载项商店文案（简体中文）

## 扩展名称

知乎动态头像助手（非官方）

## 简短说明（来自 manifest，只能通过重新上传 ZIP 修改）

在知乎当前标签页本地处理 GIF 或动态 WebP，支持自动更换头像和手动替换流程；图片仅由用户主动交给知乎原有上传流程。

## 详细说明

知乎动态头像助手是一款独立开发的非官方浏览器扩展，用于在知乎个人主页更换动态头像。选择本地 GIF 或动态 WebP 后，扩展会在浏览器内完成解析、GIF 到动态 WebP 的逐帧转换以及有效性检查，不会把图片发送给任何第三方转换服务。

你可以使用自动更换：扩展在当前知乎个人主页定位头像入口，填入本地生成的占位图，并调用页面现有的保存流程；也可以使用手动替换：先启用替换，再按知乎通常的方式选择占位图片并保存。两种方式最终都会在头像保存阶段使用准备好的完整动态 WebP。自动流程无法定位页面元素时会提示转为手动操作，不会反复提交。

扩展只在用户点击工具栏图标后访问当前标签页；替换仅对该标签页生效，刷新即失效，并会在十分钟后自动停止。准备好的图片保存在浏览器扩展本地存储中，用户可以随时停止替换或删除本地图片。扩展还提供“作者与更新”页面，只从 Cloudflare 主源或 GitHub 备用源读取经过严格校验的 JSON 文本和 HTTPS 链接，不加载远程代码。扩展不收集账号、密码、Cookie、浏览记录、分析数据或广告标识，不包含广告、订阅或内购。

注意：头像是否显示动画取决于知乎网页、客户端版本及服务端处理。知乎页面结构或上传策略变化后，扩展功能可能需要更新。请遵守知乎的服务规则，只为自己有权使用的账户和图片更换头像。

本扩展与知乎没有隶属、合作或认可关系。“知乎”仅用于说明兼容网站。核心技术思路与手动操作方式注明来源为知乎作者 Archimon 的公开文章。
