产品名称：知乎动态头像助手（非官方）
版本：2.2.0

单一用途：帮助用户将自己选择的 GIF 或动态 WebP 通过知乎现有头像编辑流程设置为动态头像。

测试步骤：
1. 在 Microsoft Edge 中登录知乎，打开自己的个人主页（URL 形如 https://www.zhihu.com/people/<用户名>）。
2. 点击扩展图标，选择一个至少包含两帧的 GIF 或动态 WebP，等待“动图已准备好”。
3. 点击“自动更换头像并保存”。扩展会填入本地生成的 PNG 占位图，等待知乎头像裁剪弹窗可保存，然后调用页面现有保存按钮。在 Canvas 导出阶段，扩展提供用户准备好的完整动态 WebP。
4. 如果页面结构使自动定位失败，状态会明确提示手动流程。点击“启用手动替换”，回到同一标签页按知乎正常流程选择任意占位图并保存。
5. 点击“停止当前页替换”可立即恢复页面 Canvas；刷新页面或等待十分钟也会恢复。点击“删除本地图片”会删除扩展存储的头像文件。
6. 点击弹窗底部“作者与更新”会打开扩展内的 author.html。该页先读取 Cloudflare JSON，失败后读取 GitHub Raw JSON，再失败则使用缓存或内置内容。远程数据不能执行代码。

权限说明：
- activeTab：仅在用户点击扩展后读取当前标签页 URL/标题并确认其属于知乎；只操作用户当时选择的标签页。
- scripting：向该标签页注入随扩展打包的 injector.js，并在页面主世界调用头像流程；没有常驻内容脚本。
- storage：在 Edge 扩展本地存储中保存用户主动选择并处理的头像、文件名、大小、帧数和 PNG 占位图。
- unlimitedStorage：动态图片经 Base64 编码可能超过 storage.local 的默认配额；扩展本身仍限制输入和输出文件最大 20MB。
- host permissions：仅允许 author.html 读取 `zhihu-avatar-author.qxzcmd.workers.dev` 和 `raw.githubusercontent.com` 上的公开 JSON。不会向这些地址发送头像、知乎页面内容或账号数据。

远程代码：否。所有 JavaScript 均包含在 ZIP 中。作者页只下载并校验 JSON 数据，使用 DOM `textContent` 渲染，不执行远程 HTML、脚本、模块或 WebAssembly。

数据：开发者不收集或接收任何用户数据。用户明确执行保存时，头像图片由知乎页面现有 HTTPS 上传流程发送给知乎。扩展不读取 Cookie、密码、私信或完整浏览历史。

兼容性：Microsoft Edge 111 及以上。需要 ImageDecoder 支持。扩展检测到不兼容环境时会显示明确错误。

品牌：本产品在名称和界面中明确标记“非官方”，不使用知乎官方 Logo，与知乎没有隶属或认可关系。
