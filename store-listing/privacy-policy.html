隐私政策

知乎动态头像助手（非官方）｜生效日期：2026 年 9 月 8 日｜适用版本：2.2.0 及以上

本扩展的单一用途是在用户主动选择图片后，帮助用户通过知乎现有的头像设置流程更换动态头像。

处理的数据

本扩展仅在实现上述功能所必需的范围内处理：

  1. 用户主动选择的 GIF 或 WebP 图片。图片在本地浏览器中解析、转换和校验，并保存在 Microsoft Edge 的扩展本地存储中，以便预览和重复使用。
  2. 用户主动打开扩展时的当前标签页 URL 和标题。该信息只用于确认当前页面属于知乎并把操作发送到正确的标签页，不会形成浏览历史记录。
  3. 当前知乎页面中与头像编辑流程有关的按钮、文件输入框、裁剪区域和保存状态。该信息仅在设备上即时处理，不会保存或发送给扩展开发者。
  4. 用户打开“作者与更新”页面时，扩展会从 Cloudflare 主源请求公开的作者信息、公告和相关链接；主源失败时请求 GitHub Raw 备用源。请求会向托管服务传输常规网络连接信息（例如 IP 地址和 User-Agent），受相应托管服务的隐私政策约束。扩展不在请求中加入知乎账号信息、头像图片或唯一用户标识。

本扩展不读取或收集知乎账号、密码、Cookie、私信、联系人、完整浏览历史、精确位置、支付信息或设备标识，也不使用分析、追踪或广告服务。

数据使用与披露

图片和页面状态仅用于用户可见的头像更换功能。本扩展不会把这些数据发送给扩展开发者，也不会出售、出租或向数据经纪商披露数据。作者页的公开 JSON 内容会缓存在扩展本地存储中，以便远程源暂时不可用时显示。

当用户明确点击“自动更换头像并保存”，或在启用手动替换后点击知乎页面的保存按钮时，用户选择并处理后的头像图片会通过知乎页面原有的上传流程发送给知乎。该传输是用户请求功能的必要组成部分，受知乎自身的条款和隐私政策约束。本扩展不控制知乎收到数据后的处理方式。

数据保存与用户控制

准备好的图片保存在 Microsoft Edge 的扩展本地存储中，直至用户点击“删除本地图片”或卸载扩展。用户可以预览、下载或删除该图片。

页面替换只在用户选择的当前标签页中临时启用。用户可以点击“停止当前页替换”、刷新或关闭该标签页来停止；扩展也会在十分钟后自动停止。卸载扩展会删除由 Microsoft Edge 管理的扩展本地数据。

安全与远程代码

图片转换完全在本地进行。本扩展不加载或执行远程代码，不使用外部转换服务，也不包含广告、支付或第三方分析 SDK。作者页只解析结构版本、长度和字段均受限制的 JSON，并只以纯文本创建页面内容；链接必须使用 HTTPS。远程内容不能注入 HTML 或 JavaScript。

儿童隐私

本扩展不面向儿童收集个人信息，也不会主动识别用户年龄。

政策更新

若功能或数据处理方式发生变化，本政策会同步更新生效日期与内容。涉及新的个人数据处理时，会在发布前更新披露并按照适用要求取得用户同意。

联系方式

隐私或支持问题请使用 Microsoft Edge 加载项商店页面中显示的发布者支持联系方式。

本扩展是独立开发的非官方工具，与知乎没有隶属、合作或认可关系。
