# 系统架构与关键决策

## 模块与数据流

本项目采用零构建依赖的原生 JavaScript 架构（Manifest V3）：

1. **媒体编解码核心 (`media.js`)**：
   - 基于 `ImageDecoder` + `OffscreenCanvas` / `HTMLCanvasElement` 的 GIF 帧合成器与 WebP RIFF (`ANIM` / `ANMF` / `VP8X`) 容器打包器与校验器。
2. **主世界注入器 (`injector.js`)**：
   - 仅在用户点击启用后通过 `chrome.scripting.executeScript`（`MAIN` 执行世界）按需注入当前激活的知乎标签页，负责 `toBlob / toDataURL` 拦截替换、自动换头像 UI 流程编排与 10 分钟自动恢复。
3. **扩展弹窗与独立页 (`popup.html / popup.js` & `author.html / author.js`)**：
   - 提供动图选择、帧信息预览、手动/自动模式触发、拦截次数回执与大文件独立页转换支持。
4. **测试与发布工具 (`tests/` & `tools/build_release.py`)**：
   - `tests/core.test.cjs` 提供 Node.js 原生测试运行器单元测试；`tests/browser.html` 提供真实浏览器 Canvas/ImageDecoder 集成测试；`tools/build_release.py` 生成扩展发布包与 SHA-256 校验。

## 关键决定

- **按需注入而非持久化 Content Script**：仅通过 `activeTab` + `scripting` 在用户主动操作时对当前知乎页执行指令，平时零页面注入开销。
- **仅调用现有 UI 流程**：自动模式仅驱动页面现有的文件输入框与保存按钮，不伪造私有上传请求或触碰用户鉴权凭据。
