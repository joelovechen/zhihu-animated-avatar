# 开发环境与构建运行说明

## 环境与运行

- **运行环境**：Chrome / Microsoft Edge（Chromium 111+）、Node.js 20+（运行单元测试）、Python 3.11+（运行发布打包脚本）。
- **工作目录**：仓库根目录（无需 `npm install` 或构建步骤，直接加载根目录即可运行）。
- **本地加载**：在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，点击「加载已解压的扩展程序」并选择仓库根目录。

## 日常构建或替代检查

指定以下命令作为日常合并前检查（在仓库根目录执行）：

```powershell
# 1. 运行核心单元测试（无需 npm install）
npm test

# 2. 生成发布构建包与 SHA-256 校验文件（输出至 local-artifacts/）
python tools/build_release.py
```

### 浏览器集成测试（按需执行）

```powershell
python -m http.server 8765 --bind 127.0.0.1
# 在浏览器打开 http://127.0.0.1:8765/tests/browser.html 点击「运行全部测试」
```
