# 产品目标与功能需求

## 目标与范围

面向知乎用户，提供一款**免费、开源、无外部运行依赖**的 Chrome / Edge（Chromium 111+）动态头像（GIF / 动态 WebP）转换与上传替换扩展（当前版本 2.2.0）。

## 主要功能

1. **本地 GIF / 动态 WebP 解码与 RIFF 封装**：
   - GIF 通过浏览器原生 `ImageDecoder` 逐帧解码与合成，Canvas 编码为 WebP 帧后按 RIFF 规范封装为动画 WebP（保留帧时长与透明度）。
   - 动态 WebP 逐帧解码校验并保持原始字节不变（仅接受至少两帧的动画）。
   - 本地安全边界保护：输入/输出最大 20MB、最大 600 帧、单帧最大 4096×4096 像素、总帧像素上限 3 亿。
2. **双模式更换流程**：
   - **手动替换模式（作者原方法）**：开启后拦截当前知乎标签页的 `HTMLCanvasElement.toBlob / toDataURL` 导出，将裁剪窗口占位图输出替换为准备好的完整动态 WebP；支持手动停止或 10 分钟超时自动恢复。
   - **自动更换模式**：在本人知乎主页自动定位头像文件输入框、填入本地生成的 PNG 占位图、等待裁剪弹窗并自动触发保存，完成后自动停止替换；定位异常时安全回退至手动模式。
3. **本地作者页与安全边界**：
   - `author.html` 依次从 Cloudflare 主源、GitHub Raw 备用源、本地缓存与内置配置读取纯文本 JSON 与 HTTPS 链接，拒绝 HTML/JS 注入。
   - 无常驻内容脚本、无后台数据采集、不读取或上传 Cookie。
